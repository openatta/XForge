# The measurement tier

Three prompts that say what a Stage must achieve and nothing about how to find out where
anything is. That omission is the whole point: the product's job is to answer "where does this
Change stand, what does this Stage owe, and what do I need to read" — so a prompt that answers it
first makes the product's answer unmeasurable.

The guided prompts beside these are not wrong; they are a regression tier and they are allowed to
hand the model whatever gets it reproducibly to the end. But a refactor that removed most of a
Stage's orientation measured 3% against them, because they open by instructing the very reads it
removed. `check-vocabulary.mjs` enforces the difference.

Same task, same fixture, same model on both sides of a change. What differs is only the code under
test.
