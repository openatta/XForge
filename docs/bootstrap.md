# XForge Bootstrap Guide

The canonical Protocol 2 bootstrap and installation procedure is the
root-level [XForge Agent Installation Runbook](../AGENT_INSTALL.md).

Use that runbook for both source-built and exact npm-package installation. It
includes Scaffold verification,
collision-safe localization, CLI/Lock identity bootstrapping, Managed-mode
activation, Adapter dry-run review, runtime `PATH` validation, and acceptance
criteria.

Do not use an older Protocol 1 bootstrap procedure with the current
`@xforge/cli 0.4.1` Scaffold.
